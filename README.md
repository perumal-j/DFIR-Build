# DFIR-Build
DFIR-Build is an Ansible project customizes your VM for Digital Forensics & Incident Response. It can mainly be used in Ubuntu OS (with MATE terminal). 

## Prerequisite:
Firstly, Run `ansible_installation.sh` to install ansible & other components for hassle free parrot building.
